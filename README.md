# 🖥️TaskManager Front-end
Interface moderna para gerenciamento de tarefas, desenvolvida com **React + Vite**.

## 🚀Tecnologias
- React 19
- Vite
- Lucide React (ícones)
- CSS Variables + Glassmorphism

## ✨Funcionalidades
- ✅ Criar, editar e remover tarefas
- ✅ Marcar tarefas como concluídas
- ✅ Busca por título em tempo real
- ✅ Contador de tarefas e concluídas
- ✅ Design dark premium com efeitos de hover
- ✅ Integração com a Tasks API

## ⚙️Como rodar
```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`

> ⚠️ A [Tasks API](https://github.com/taaehy/tasks-api) precisa estar rodando em `http://localhost:3333`
